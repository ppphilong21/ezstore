# EZStore 業務知識庫（OKF bundle）

EZStore B2B 報價與訂單系統的企業知識：報價政策、資料實體、指標、作業流程、專案經驗教訓（lessons learned）與系統中的 AI Agent。
Sales Advisor Agent 以「先讀 index、再讀概念、沿連結走」的方式使用這份知識；政策數值是本作業為範例公司 EZStore 訂定的業務規則。

# 目錄

* [policies/](policies/) - 報價因子區間、利潤率下限、核准層級、信用與轉訂單規則
* [entities/](entities/) - 報價單、訂單、客戶、客戶等級、產品的定義與欄位
* [metrics/](metrics/) - 總價、利潤率等計算公式
* [processes/](processes/) - 先複製再修改、報價單生命週期、轉訂單檢核
* [lessons-learned/](lessons-learned/) - 開發與營運 EZStore Agent 的經驗教訓
* [agents/](agents/) - 系統中的 AI Agent 與它們的 A2A 介面
